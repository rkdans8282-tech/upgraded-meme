## 4. 차별화 (경쟁: GoodNotes, Notability, 각종 다꾸 앱)

필기앱은 **범용·기능 중심**, 이 앱은 **감성·꾸미기 중심**으로 간다.

1. **질감과 소리**: 책장 넘김, 종이 질감, 연필 소리 (이미 구현). 스크린샷·영상으로 가장 잘 전달되는 강점.
2. **5분 완성**: 템플릿과 스티커 덕분에 처음 쓰는 사람도 예쁘게 완성.
3. **내 사진 → 내 스티커**: 사진을 손으로 오려 바로 스티커로. (유료 기능 후보)
4. **소규모 감성 브랜드**: 스티커 세계관·시즌 팩으로 팬층 형성.

> 경쟁 앱의 최신 가격·기능은 출시 전에 직접 설치해서 비교한다. `[확인 필요]`

- 시즌 스티커팩 정기 발매
- 일본어 UI (i18n 구조는 MVP에 포함, 폰트 추가)

### 5.3 v2 (AI 기능, 반응 보고 결정)

- AI 일기 초안 (사진+한 줄 메모 → 문장)

## 7. 성장(마케팅) 전략

앱 출시보다 **콘텐츠가 먼저**다.

1. **개발 과정 + 완성 화면 영상**을 유튜브 쇼츠/릴스/틱톡에 꾸준히 업로드 (책장 넘기는 소리, 꾸미는 과정은 영상 매체와 궁합이 좋음)
2. 매주 **"이 스티커로 꾸민 하루" 콘텐츠** → 앱 링크 연결
3. **다꾸 유튜버/인스타 계정 소규모 협업** (무료 프로 계정 제공)
4. 앱스토어 최적화(ASO): 키워드(다이어리, 다꾸, 스티커, 일기장, journal, sticker diary), 스크린샷 6장 중 첫 장에 질감·스티커 강조
5. 출시 전 **대기자 명단**(간단한 소개 페이지)과 **TestFlight 베타 30~50명**

## 8. 기술/운영 요구사항

### 8.1 스택

- **Expo(React Native) + EAS Build/Submit** → Mac 없이 빌드·제출 가능 `[확인 필요: EAS 요금제/무료 빌드 한도]`
- 그리기: **`react-native-svg`** (Expo Go에서 바로 동작. 획이 매우 많아져 느려지면 Skia로 교체 검토)
- 제스처: `react-native-gesture-handler` / `reanimated` (스티커에 이미 사용 중이면 재사용)
- 사진: `expo-image-picker`
- 결제: RevenueCat (`react-native-purchases`) — **Expo Go에서는 동작하지 않으므로 개발 빌드(dev client) 필요**
- 알림: `expo-notifications`, 잠금: `expo-local-authentication`
- 백업: `expo-file-system` + `expo-sharing`
- 크래시/분석: Sentry, 간단한 이벤트 분석(PostHog 등) — 개인정보 최소 수집

> 프로젝트 지침(`app/AGENTS.md`)에 따라 Expo API는 기억에 의존하지 않고 **버전별 공식 문서를 확인한 뒤** 구현한다.

### 8.2 데이터 설계 변경

현재 `Entry = { mood, text, stickers }` 에 아래를 추가한다.

```ts
type Stroke = { tool: 'pen' | 'marker'; color: string; width: number; points: number[] };
type PhotoItem = { id: string; uri: string; x: number; y: number; scale: number; rotation: number };
type Entry = { mood?; text?; stickers?; strokes?: Stroke[]; photos?: PhotoItem[] };
```

- 사진은 AsyncStorage에 넣지 말고 **앱 문서 폴더에 파일로 복사**하고 경로만 저장 (용량·성능).
- 데이터 버전 필드(`schemaVersion`)를 두어 이후 마이그레이션에 대비.
- 일기가 많아지면 AsyncStorage 한 덩어리 저장이 느려지므로 v1.1에서 파일/SQLite 분리 검토.

### 8.3 성능

- 스티커·획이 많은 페이지에서도 60fps 유지 목표 (획은 Skia Path로 묶어 렌더).
- 사진은 저장 시 최대 변 2048px로 리사이즈.
