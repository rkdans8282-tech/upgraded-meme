# 락메모 (LockMemo)

잠금화면에서 최대한 빠르게 메모하는 iOS 앱. 세 가지 방법을 제공합니다.

| 방법 | 위치 | 동작 |
|---|---|---|
| **알림 입력창** ⭐ | 잠금화면 알림 영역 (노란 박스 자리) | 알림을 당기면 키보드가 열리고, **잠금 해제·앱 실행 없이** 바로 저장 |
| 잠금화면 위젯 | 시계 위/아래 | 탭 → 앱이 열리며 입력창 + 키보드 즉시 활성화 (최신 메모도 표시) |
| 컨트롤 (iOS 18+) | 잠금화면 하단 버튼 | 손전등/카메라 자리에 "새 메모" 버튼 배치 |

> ⚠️ iOS 위젯에는 텍스트 입력창을 넣을 수 없고, 잠금화면 아무 곳에나 위젯을 놓을 수도 없습니다(시계 위·아래만 가능).
> 그래서 노란 박스 영역에서 바로 입력하는 효과는 "알림의 텍스트 입력 액션"으로 구현했습니다.

## 빌드 방법 (Mac 필요)
```bash
brew install xcodegen
cd LockMemo && xcodegen      # LockMemo.xcodeproj 생성
open LockMemo.xcodeproj
```
1. 두 타겟(LockMemo, LockMemoWidget) Signing에서 본인 Team 선택
2. 번들 ID(`com.example...`)와 App Group(`group.com.example.lockmemo`)을 본인 것으로 바꿈
   (`project.yml`, `Shared/MemoStore.swift`)
3. 실기기에서 실행 → 알림 허용

## 사용 설정
- 알림 입력창: 설정 → 알림 → 락메모 → 잠금화면 표시 켬. 알림을 **아래로 당기기/길게 누르기** → "메모 쓰기"
- 위젯: 잠금화면 길게 누름 → 맞춤화 → 위젯 추가 → 락메모
- 컨트롤: 맞춤화 → 하단 버튼 → "새 메모"

## 한계
- 알림은 제출 후 사라지고 앱이 즉시 다시 올립니다(앱이 종료된 상태에선 재게시가 지연될 수 있음).
- Xcode 없는 환경에서 작성되어 **아직 빌드/실행 테스트를 하지 못했습니다.**
